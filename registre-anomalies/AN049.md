# AN049 — Code des transports R5795-5 : adaptation fondée sur l'article R. 4623-29 du code du travail, absent du Code du travail en vigueur

## Texte et article

Code des transports, art. R5795-5, version du 17/04/2025 : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000051481332.

## Constat vérifiable

L'article prévoit que les mots « les articles R. 4311-34 à R. 4311-41-2 du code de la santé publique et l'article R. 4623-29 du code du travail » sont remplacés par des mots propres aux Terres australes. Le Code du travail en vigueur compte R4623-28 et R4623-30 mais pas R4623-29.

## Cas concret

Une adaptation d'outre-mer vise des mots d'un texte dont l'un des articles n'existe plus.

Le texte adapté peut viser une rédaction historique d'un autre texte (c'est la technique de l'adaptation) ; la référence morte serait alors celle du texte d'origine, non de cet article.
