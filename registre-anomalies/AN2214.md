# AN2214 — Code de l'éducation L212-1 : « ci-après reproduit » l'article L2121-30 du CGCT dans sa version d'avant 2022, sans le II ajouté depuis

## Texte et article

Code de l'éducation, art. L212-1 ; Code général des collectivités territoriales, art. L2121-30, L212-1 : version du 15/04/2003 ; CGCT L2121-30 : version du 22/02/2022 : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524507. L212-1 ; CGCT L2121-30.

## Constat vérifiable

L212-1 reproduit « les dispositions de l'article L. 2121-30 du code général des collectivités territoriales, ci-après reproduites » : la phrase sur les écoles. L2121-30 du CGCT est devenu un article à deux parties (I : écoles ; II : dénomination des voies) en 2022. La reproduction du code de l'éducation est incomplète sans le dire, et elle ne vaut pas modification : L212-1 attribue la **création et l'implantation** au conseil municipal mais **ni L212-1 ni L2121-30 n'écrivent la suppression** d'une école.

## Cas concret

Un lecteur du code de l'éducation croit lire le texte en vigueur du CGCT ; il lit une copie, et une règle sur la suppression d'école n'existe dans aucun des deux.

## Gravité

**Faible** (duplication) ; la lacune sur la suppression d'école est notée pour la mesure 18 (⚠️ jurisprudence non lue).

## Correction proposée

Remplacer la reproduction par un simple renvoi à L2121-30, et écrire qui décide la suppression ou le regroupement d'une école.

## Objection ou interprétation contraire

La suppression d'école est traitée par la pratique et la jurisprudence administratives (non lues) ; le code n'a pas à l'écrire pour que la règle existe.
