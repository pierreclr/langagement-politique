# AN2205 — Code de l'éducation : le conseil départemental porte quatre noms (« conseil de l'éducation nationale », « conseil départemental de l'éducation nationale », « conseil départemental de l'éducation », « conseil territorial »)

## Texte et article

Code de l'éducation, art. L235-1, L211-1-1, L211-2, R235-11, D211-9, L235-1 : version du 20/12/2014 ; R235-11 : 31/12/2021 : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000029945544. L235-1 (institution) ; R235-11 (compétences) ; L211-1-1, L211-2, D211-9 (consultations sur les fermetures et le nombre moyen d'élèves par classe).

## Constat vérifiable

L235-1 institue « le conseil de l'éducation nationale … dans chaque circonscription départementale » ; R235-11 le désigne « le conseil départemental de l'éducation » ; vingt-trois articles disent « conseil départemental de l'éducation nationale » (dont D211-9, qui écrit en outre « prévue » au féminin) ; L211-2 mentionne le « conseil académique de l'éducation nationale ». Le même organe, consulté sur la répartition des emplois d'enseignants (R235-11 1° b)), est nommé de trois façons.

## Cas concret

Un lecteur qui cherche « conseil départemental de l'éducation » dans le code ne retrouve ni L235-1 ni les articles de 2026 sur les fermetures de classes.
