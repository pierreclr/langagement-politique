# AN039 — Code du sport L121-8 : renvoi à l'article L. 432-8 du code du travail, numérotation d'avant 2008

## Texte et article

Code du sport, art. L121-8, version du 25/05/2006 : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006547507.

## Constat vérifiable

« Cette association est constituée conformément à l'article L. 121-1 du présent code et à l'article L. 432-8 du code du travail. » La numérotation L432-8 est celle d'avant la recodification du Code du travail de 2008 ; aucun article L432-8 n'est en vigueur dans le Code du travail.

## Cas concret

Le régime de l'association sportive d'entreprise renvoie à une règle sans objet identifiable ; le lecteur doit deviner l'article actuel.

## Contre-vérification (04/11/2026, 5e lot)

**Verdict : tient (corrige la relecture du 03/11), gravité ramenée à faible.** Texte relu : L121-8 du code du sport (version du 25/05/2006, inchangée) cite « l'article L. 432-8 du code du travail ». Base LEGI relue : cet article a une dernière version « ABROGE » qui va du 18/07/2001 au 01/05/2008 : il a été en vigueur jusqu'à la recodification du 01/05/2008. La relecture du 03/11 avait lu la date de début de la dernière version comme une date d'abrogation (« abrogé le 18/07/2001 ») : c'est une erreur de lecture, la fiche d'origine (« numérotation d'avant 2008 ») était exacte. Le renvoi était donc valide à la création de L121-8 (2006) et est mort le 01/05/2008. Défaut de coordination réel, rattrapable par la table de concordance : gravité faible. (⚠️ V12893 : table de concordance de l'ordonnance de recodification du code du travail (2007) : non lue.)
