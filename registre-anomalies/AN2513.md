# AN2513 — Cinq calendriers de montée en charge pour un seuil de cinquante salariés : douze mois (délégué syndical), vingt-quatre mois (CSE complet, règlement intérieur), trois ans (index), deux exercices (comptes), cinq années civiles (participation, PEEC, formation)

## Texte et article

Code du travail L2143-3; Code du travail L2312-2; Code du travail L1311-2; Code du travail D1142-8; Code de la sécurité sociale L130-1; Code de commerce D230-1.

## Constat vérifiable

Quand une entreprise atteint cinquante salariés : le délégué syndical peut être désigné après douze mois consécutifs (L2143-3) ; le CSE exerce ses attributions complètes et le règlement intérieur devient obligatoire douze mois après les douze mois (L2312-2, L1311-2) ; l'index d'égalité s'applique après trois ans (D1142-8) ; les seuils comptables sont franchis à la clôture de deux exercices consécutifs (D230-1) ; la participation, le PEEC, le local de restauration, la formation s'appliquent après cinq années civiles (L130-1 II). R243-6-3 CSS ajoute un maintien de quatre années d'un régime de versement en lieu unique « nonobstant les fluctuations d'effectifs ».

## Cas concret

Entreprise qui passe à 50 le 1er janvier 2027 et y reste : délégué syndical possible en janvier 2028, CSE complet et règlement intérieur en janvier 2029, index en 2030, participation et PEEC à partir de 2032.

Citations : `python3 -I outils/droit/registre.py --verifier AN2513`.

## Gravité

**Moyenne** pour la lisibilité, mais ce n'est pas une contradiction : chaque calendrier a une raison (représentation du personnel d'un côté, charges financières de l'autre).

## Correction proposée

Le manifeste propose de supprimer les seuils (fonctions continues, document de travail de l'atelier, non publié) ; à défaut, un seul calendrier (par exemple L130-1 II) pour tout le seuil de 50.

## Objection ou interprétation contraire

Les représentants du personnel doivent pouvoir être désignés vite et les charges financières lissées : plusieurs calendriers sont un choix de politique assumé (PACTE a gardé le décompte du code du travail pour la représentation, selon France Stratégie).
