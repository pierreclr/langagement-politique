# AN1207 — Trois décrets du code de la sécurité sociale (R241-0-1, R241-0-4, D241-1-1) citent cinq articles du code du travail d'avant la recodification de 2008 (L351-4, L351-12, L321-2, L721-1, L771-1)

## Texte et article

Code de la sécurité sociale, art. R241-0-1 I ; R241-0-4 ; D241-1-1 2°, version du 19/11/2016 (Décret n°2016-1551 du 18 novembre 2016 - art. 6) : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033471281.

## Constat vérifiable

R241-0-1 I (version du 19/11/2016) vise « l'obligation édictée à l'article L. 351-4 du code du travail » et « l'article L. 351-12 du même code » ; R241-0-4 (2005) vise « la procédure de l'article L. 321-2 du code du travail » ; D241-1-1 (version du 29/09/2018, donc écrite dix ans après la recodification) vise « l'article L. 721-1 du code du travail » et « l'article L. 771-1 du même code ». Ces numéros sont ceux du code du travail d'avant le 1er mai 2008 (LEGI : tous abrogés à cette date). L'obligation d'assurance chômage de L351-4 est aujourd'hui à L5422-13, que L241-13 II 1° cite correctement.

## Cas concret

Un employeur de salarié à temps partiel qui veut maintenir l'assiette vieillesse (L241-3-1) doit vérifier qu'il est soumis à « l'article L. 351-4 du code du travail » : le texte à lire est L5422-13, mais le décret ne le dit pas. Pour D241-1-1, un décret de 2018 reprend sans mise à jour des numéros abrogés dix ans plus tôt.

## Gravité

**Faible.** Sens retrouvable, mais cinq numéros morts dans trois décrets d'application d'un même régime (assiette vieillesse du temps partiel), dont un écrit en 2018.

## Correction proposée

Mise à jour par décret (tables de concordance du décret de recodification) : L351-4 → L5422-13 ; L351-12 → L5424-1 ; L321-2 et L721-1, L771-1 → articles correspondants du code du travail actuel (⚠️ correspondances à lire dans les tables de concordance : V11356).

## Objection ou interprétation contraire

Les tables de concordance de l'ordonnance de 2007 rendent la substitution mécanique : l'administration et les juges lisent les anciens numéros avec la table ; il n'y a pas de doute d'application, seulement un défaut de mise à jour (le même défaut que pour AN118, L351-5).
