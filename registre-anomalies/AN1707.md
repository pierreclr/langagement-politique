# AN1707 — R512-2 : le plafond de rémunération de l'enfant vise « les articles L. 141-1 à L. 141-9 du code du travail », abrogés le 01/05/2008 (Smic : L3231-1 et suivants)

## Texte et article

CSS R512-2 (décret n° 2000-71 du 28 janvier 2000, jamais modifié depuis).

## Constat vérifiable

R512-2 fixe à vingt ans l'âge jusqu'auquel les enfants ouvrent droit aux prestations familiales si leur rémunération est inférieure à « 55 % du salaire minimum interprofessionnel de croissance défini aux articles L. 141-1 à L. 141-9 du code du travail, multiplié par 169 ». Ces neuf articles sont abrogés depuis le 01/05/2008 (ordonnance n° 2007-329, concordance vers L3231-1 et suivants) ; le Smic est aujourd'hui défini aux articles L3231-1 à L3231-11 du code du travail, que D531-9 cite correctement. Le texte est resté dans sa rédaction de 2000 et le renvoi pointe vers du vide (même cas que AN039 et AN050).

## Cas concret

Un lecteur qui cherche L141-1 dans le code du travail ne trouve rien ; la règle s'applique tout de même, par concordance.

`python3 -I outils/droit/registre.py --verifier AN1707`.

## Gravité

Faible : la concordance est évidente et le renvoi n'empêche pas l'application.

## Correction proposée

Remplacer par « L. 3231-1 à L. 3231-11 ».

## Objection ou interprétation contraire

Le renvoi est périmé mais non ambigu ; le coût de la correction est nul.
