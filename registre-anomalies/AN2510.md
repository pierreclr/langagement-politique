# AN2510 — BDESE : R2312-9, dans sa version du 06/07/2024, renvoie trois fois à « l'article R. 225-105 du code de commerce », abrogé depuis le 01/01/2021

## Texte et article

Code du travail R2312-9.

## Constat vérifiable

R2312-9 (version du 06/07/2024, décret n° 2024-690 du 05/07/2024) fixe le contenu de la base de données économiques, sociales et environnementales des entreprises « d'au moins trois cents salariés ». Le 10° du tableau distingue les entreprises « soumises à la déclaration prévue à l'article R. 225-105 du code de commerce » (rubrique I) et les autres (rubrique II). La base LEGI donne pour R225-105 du code de commerce une dernière version ABROGEE à compter du 01/01/2021 ; l'article n'est pas dans le code en vigueur. Le texte du décret de 2024 cite donc, trois ans et demi après son abrogation, un article qui n'existait plus : l'obligation visée (déclaration de performance extra-financière) est désormais ailleurs (V12938).

## Cas concret

Une entreprise de 400 salariés cherche à savoir quelles informations environnementales elle doit mettre dans sa base : le décret l'invite à vérifier si elle est « soumise à la déclaration prévue à R225-105 », qui n'existe plus.

Citations : `python3 -I outils/droit/registre.py --verifier AN2510`.

## Gravité

**Faible.** Sans effet sur les montants, mais l'article porte sur le seuil de 300 salariés et sur les informations remises aux élus.

## Correction proposée

Remplacer par le renvoi à l'article actuel de déclaration de durabilité ou de performance extra-financière.

## Objection ou interprétation contraire

Le décret de 2024 peut avoir maintenu volontairement une référence à l'ancienne rubrique pour les entreprises tenues par des textes antérieurs : non repéré dans les considérants (V12938).
